## 📌 Описание на проекта

JobsBG е релационна база данни, симулираща функционалност, подобна на платформи за работа като Jobs.bg.  
Проектът включва:

- Концептуален модел (Chen)
- Логически модел (Crow’s Foot)
- Физически модел (UML)
- Реална база данни в MS SQL Server
- Съхранена процедура, функция и тригер
- Тестови данни
- Data Warehouse
- Power BI Dashboard

---

# 🛠 Инструкции за стартиране

## 1. Изисквания
- MS SQL Server  
- SSMS 
 
В SSMS:
1. Изпълнява се JobsBG_Db_Create.sql за създаване на структурата
2. Изпълнява се JobsBG_Db_Fill_Data.sql за създаване на записи
3. Изпълнява се JobsBG_Db_Proc_Func_Trigger.sql за създаване на функция,процедура и тригер
